# Деплой

[English version](deploy.md)

## Сервер projects

Приложение живёт на сервере `projects` в `/srv/community-taplist`. Порты 80/443, TLS и домен
`taplist.aimuzov.online` держит общий Caddy из `aimuzov-projects/infra-server`, он ходит в
контейнер `community-taplist:80` по сети `edge`. Пароль на `/editor` Caddy спрашивает тот же, что
задан в `PRIVATE_EDITOR_SECRET`, поэтому браузер вводит его один раз.

Пуш в `main` запускает GitHub Actions: проверки, затем вход по SSH на сервер. Ключ из секрета
`DEPLOY_SSH_KEY` привязан к [`deploy/remote.sh`](../deploy/remote.sh): он подтягивает `main` и
пересобирает контейнер из [`deploy/docker-compose.yml`](../deploy/docker-compose.yml). Повторить
выкладку без пуша: `gh workflow run deploy.yml`.

`.env` лежит на сервере рядом с репозиторием, образец в [`.env.example`](../.env.example). `PORT`
и `ORIGIN` задаёт compose.

## Откат

Откатить выкладку -- значит сделать `git revert` плохого коммита в `main` и запушить: Actions
соберут прежнюю версию тем же путём.

## Память

Контейнер ограничен 160 МБ (`mem_limit`), куча Node -- 96 МБ. Приложению этого хватает, и оно не
отнимет память у соседних проектов.

В образе `BODY_SIZE_LIMIT` adapter-node поднят до 16 МБ: редактор сохраняет весь список вместе с
обложками, и в стандартные 512 КБ он не влезает.

## Телевизоры

Откройте `https://taplist.aimuzov.online` в браузере телевизора в полноэкранном режиме и выберите
экран пультом, RETURN возвращает обратно. Вёрстка рассчитана на 1920×1080 и масштабируется под
1280×720. Табло запрашивает свежие данные каждые `PUBLIC_DATA_UPDATE_INTERVAL` миллисекунд, а
после нового деплоя один раз перезагружается.

Клиентский бандл собирается под Chromium 68 (LG webOS 5). На более старых телевизорах табло
показывается, но без навигации с пульта и обновления данных.
